# HR Employee Attrition Analysis (Excel)

## Project Overview

This project analyzes the IBM HR Employee Attrition dataset using Microsoft Excel to identify employee attrition trends, workforce patterns, and key HR metrics. The project includes data cleaning, duplicate validation, KPI creation, pivot table analysis, and an interactive dashboard for business reporting.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Conditional Formatting
* Dashboard Design

## Project Workflow

* Cleaned and prepared the HR dataset.
* Checked and removed duplicate records.
* Created key performance indicators (KPIs).
* Built pivot tables and charts.
* Designed an interactive dashboard for HR insights.

## Workbook Structure

| Sheet                 | Purpose                  |
| --------------------- | ------------------------ |
| HR-Employee-Attrition | Original dataset         |
| Duplicate_Check       | Duplicate validation     |
| Prepared_Data         | Cleaned dataset          |
